Bulk import products

Spreadsheet needs a header row with a Name column — Category, Price, and Description are optional. Item Number is always auto-generated from the category, same as adding one product at a time.

Optional: a zip or rar of catalogue files named 1.ext, 2.ext, 3.ext… — matched by position to your spreadsheet rows (file "1" attaches to the first row, "2" to the second, and so on).
